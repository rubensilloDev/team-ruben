## 📌 Descripción del Proyecto

Este proyecto consiste en una plataforma web estática que simula un negocio digital enfocado en la salud y el rendimiento físico. A través de la web, se ofrecen servicios integrales de asesoramiento online (entrenamientos personalizados y planes nutricionales), así como un catálogo de cursos formativos para usuarios que buscan mejorar sus hábitos o profundizar en el mundo del fitness.

El objetivo principal es demostrar los conocimientos adquiridos en el diseño, maquetación e interactividad web utilizando únicamente tecnologías fundamentales del lado cliente.

---

## Características Principales

- **Diseño Responsive:** Adaptado a dispositivos móviles, tablets y ordenadores mediante media queries y Flexbox/CSS Grid.
- **Catálogo de Servicios:** Detalle de asesorías 1 a 1 de entrenamiento físico y pautas nutricionales.
- **Sección de Cursos:** Tarjetas informativas con los cursos online disponibles (temarios, duración, precios).
- **Formulario de Contacto:** Formulario conectado con una API de telegram.
- **Testimonios y Preguntas Frecuentes (FAQ):** Sección interactiva tipo acordeón para resolver dudas frecuentes.

---

## Tecnologías Utilizadas

- **HTML5:** Marcado semántico para mejorar la accesibilidad y el SEO básico.
- **CSS3:** Estilos personalizados, animaciones suaves, diseño adaptable mediante CSS Grid y Flexbox.
- **JavaScript (Vanilla):** Interactividad del DOM, validación de formularios y cálculos dinámicos.
